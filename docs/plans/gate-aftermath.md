# Gate and aftermath foundation

Approach follows the commissioned Array. Four named feeder indicators display actual Field, Stand, Drowned and Array completion. Its service latch opens a permanent return to the Stand. All four projects are required to enter the Gate.

The final sequence applies known operations: latch local feeds, isolate the common return, run a two-second diagnostic, then commit. Missing prerequisites consume nothing. Every operation saves transactionally, and a failed completion save must not set `signal_restored`. No optional archive, Wire repair or collection count is added to the four required feeder projects.

The aftermath remains a playable room with returns to the Gate and Field. Abilities, map discoveries, repairs and ending state persist. No forced reset, sacrifice or new loop replaces the completed world. The source map shows these return routes.

State tests verify each feeder independently, ordering, diagnostic completion, failed-save rollback, optional archive exclusion, reload and post-ending travel. Controller tests cover the Approach latch climb, Gate controls and aftermath return. Render review covered missing feeders, ready commissioning, completion and source map; labels crossing circuit wires were corrected.

This closes the basic progression foundation, not the full polished game. See `RELEASE-GATES.md` for the remaining direct evidence and production work. Component tests do not replace fresh full-game playthroughs or the broader level-design/art/audio pass.
