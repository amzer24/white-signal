# Stand map connections

The Stand page now names the departure points for district exits. A departure appears only after visiting its room; its destination stays `?` until visited. This preserves fog of war while making the return route legible. The strip identifies Rim / Field, Sluice / Drowned, Bridge / Wire, and Court / Source. These are route references, not claims that a locked exit is open.

Verification: expanded Stand checks cover hidden, hinted, and named connections alongside repair and save regression checks. The map capture checks layout at the native 480 by 270 viewport.
