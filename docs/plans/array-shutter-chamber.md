# Array shutter chamber: first playable pass

Optional branch from the Inspection Bay upper walk, returning to the Array core. Goal: choose between an immediately powered upper exit and an unpowered lower projector; divert the supply to inspect the memory, then retain an independent copy to power both branches and open the reverse shortcut from the core. It is a safe spatial demonstration of the story: local copies survive loss of the common feed.

## Blocks

- Entry and visible fallback: floor y224 across the room, Inspection exit x27. Central lever x210. No pit, timer, darkness damage or mandatory ability.
- Lower projector: x420/y217. The lower supply permits replay and transactional archive persistence. Upper supply rejects archive interaction with a specific cue.
- Upper return: four 34px climbs via x70/y190, x130/y156, x190/y122, x250/y88. Core exit x420/y81. Both branches remain visible; light changes destination availability, not collision.

| State | Projector | Upper exit | Core reverse shortcut |
|---|---|---|---|
| Upper supply, no copy | Unpowered | Open | Closed |
| Lower supply, no copy | Powered | Closed | Closed |
| Copy retained, either selector | Powered | Open | Open |

Selector is temporary and resets to upper on entry/death. Archive and reverse shortcut persist. A failed save grants neither. Archive is optional; it does not gate campaign completion. The map includes the discovered chamber and local-copy status.
