# Wire and Array foundation

Three rooms add the inspection shelter, suspended carriage crossing and Array diagnostic. Stand restoration plus Dash opens the Wire approach. Drowned restoration opens its freight connection into the Array. The inspection spare is reachable before repairing the carriage. Array-first players commission the diagnostic, then gain a safe service stair to the inspection shelter; the unrepaired opposite carriage shore stays gated.

The unique brake assembly persists through death. Both shores can summon the carriage, and its onboard control changes direction. Temporary carriage position resets to the left dock on room entry or death; the repair stays saved. The right recall prevents an Array-side arrival from becoming stranded. Actual controller tests verify collection, boarding, both directions and the Array control route using base movement.

The replayable Array diagnostic shows a common-return fault while a healthy feed remains lit. The player tests, isolates and bypasses. An untested or unisolated circuit cannot commission. Completion persists and replay does not undo it. This is a safe scale-model demonstration; no diagnostic damage affects the player.
