# WHITE SIGNAL full-game implementation plan

> Execution: coordinated in this task. Use the executing-plans and subagent-development workflows; review generated changes before integration.

**Goal:** Build an exploration campaign of eight connected districts with permanent abilities, persistent repairs, a coherent story, readable hazards, pixel art and 8-bit music.

**Architecture:** Keep the existing three-relay run available while developing an isolated exploration mode. Stable room/object IDs and a separate versioned save own permanent discoveries and repairs. Room data, mechanics, presentation and audio are separate so later districts reuse proven interactions.

**Tech stack:** Godot 4.7.2 Compatibility renderer, 480×270 logical viewport, GDScript, existing movement controller and pixel font. The primary agent owns architecture, integration, validation and review. Suno supplies candidate chiptune music; the refreshed PixelLab subscription is working.

**Execution update:** Ollama `glm-5.3-flash:cloud` returned truncated reasoning instead of usable deliverables on both attempts; none was applied. The primary agent implemented the save and exploration code. OpenCode was recovered using isolated configuration paths and network access, and supplied the reviewed Drowned asset brief at reported cost zero. Source-code review remains local. PixelLab completed the window sprite and first terrain candidate. Darker **Dead Carrier** Suno candidates supersede the unselected Answering Window music; neither has been integrated or loop-verified.

**Map delivered in the first slice:** M opens a paused room map immediately. Visited rooms show names, adjacent unknown rooms show faint signals, and distant rooms remain hidden. The current room is marked YOU. The service survey at Drain Lookout adds the Drowned Array clue. Visited rooms, surveys and shortcut flags persist after death and reload. This is a six-room connection map, not the finished eight-district spatial atlas. Future district surveys can reveal regional outlines while room interiors remain unexplored.

## Milestone 1 — a place that remembers

First release target: six-room Listening Field slice, entered from a clearly labelled title action. This is a foundation release, not a claim that all eight districts are finished.

### Task 1: separate exploration persistence

Create `scripts/exploration_save.gd` and `scripts/exploration_save_test.gd`. Use `user://ws_exploration_v1.json`, never the legacy campaign or settings paths. Store schema version, current room, visited rooms and named boolean discovery/repair flags. Save temporary data before replacement; preserve a recoverable previous copy. Validate input before changing live state. A failed save must leave the in-memory completed-state transaction and disk recovery story explicit.

First test must fail without the module. Then verify: new state; permanent Dash after reload; return-lift persistence; invalid room/flag types rejected; malformed current file recovery from a valid backup; no modification of legacy campaign data; safe failure handling. Run using the supplied Godot executable in headless mode, inspecting the failure summary rather than only the shell exit status.

### Task 2: exploration scene and room contracts

Create `scenes/exploration.tscn`, `scripts/exploration_world.gd`, `scripts/exploration_rooms.gd` and `scripts/exploration_test.gd`. Reuse the existing player controller and draw utilities. No movement tuning changes for this milestone. Exits use explicit context interaction near a visible doorway; transition to a tested dry spawn anchor. Each room fits a known camera view before tall-room expansion.

Rooms: Triangulation Hub, West Workshop, Ballast Gallery, Upper Amplifier, Counterweight Return and Drain Lookout. Keep the lower lead meaningful through a small discovery and a clear preview of Drowned. Use distinct compositions, not six copies of one horizontal corridor. Safe wall-kick practice and a harmless plate-shutter lesson precede dangerous variants.

### Task 3: Borrowed Current and lasting Dash

The gallery selector powers a lift or receiver. Ride to the catch; engaging it retains the platform and unfolds a permanent stair. Divert power to restore the west ear; only then open the amplifier. Find Dash, use it in a safe practice space, then open the return door from the far side. Reverse entry must not bypass the receiver puzzle. Reward and shortcut persist through death/reload. Do not show random drafts in exploration mode.

### Task 4: the answering window

The hub shows an identifiable dark window. The workshop memory shows two Operators cooperating on an unfinished repair. Repair changes the window to a stable lit pattern, visible again from the return. Replayable memory and deliberate-isolation clue survive reward collection. Initial art can use existing drawing primitives; do not claim those are PixelLab assets.

### Task 5: entry, pause and verification

Modify `scripts/menu_ui.gd` narrowly to add exploration entry without crowding existing controls. Exploration must support pause, respawn, return to title and explicit save-error feedback. Existing tutorial music and run saves remain intact. Run legacy campaign/settings checks plus exploration save/state checks. Capture the actual scene and check readable movement at the logical resolution. Install only reviewed changed files using baseline hashes.

## Milestone 2 — Drowned and Stand mechanic trials

Build Drowned's basin first as an isolated room: manual bleed works before recovering the impeller; high/middle/low markers, dry escape and control stairs, safe low-water reset, recovered part survives death. Install impeller, power the guided float, latch the upper conduit and unlock freight. Add permanent Air Jump only after the base geometry works. Swimming, ledge grabbing and unrestricted climbing are separate experiments, not assumed features.

Stand introduces a safely observed conductor, held charge and latched bridge. Ambient lightning never sets lethal timing. Reduced-flash and sound-off cues must preserve the same information. Collapse trials are bounded, optional and bypassable after completion. Build both orders of arrival before connecting these districts into the campaign.

## Milestone 3 — connected world and repair diversity

Expand the six-room Field into its two complete loops and three distinct ears. Add Flats, Stand and Drowned connections, persistent district map and two independently useful leads. Revisit rewards include roof routes, archives and shorter transport, not only currency. Required paths use guaranteed abilities; unique repair parts take no ability slots and fit through contextual interactions.

## Milestone 4 — Wire, Array and the midpoint

Wire has safe inspection shelves, a spare brake assembly and recallable carriage; the spare is reachable without the broken carriage. Array accepts either Wire or freight arrival and teaches selectors/counterweights through existing contracts. At first commissioning, a replayable diagnostic contains a branch fault while another remains stable. This midpoint must work in either region order.

## Milestone 5 — Approach, Gate and aftermath

Approach opens the service return to Stand and displays actual incomplete feeder projects. Gate requires Field, Stand, Drowned and Array restoration. Apply known operations: latch local feeders, isolate faulty common return, test and commit. Failed diagnostics consume nothing. The Spark, abilities, restored routes and revisitable world remain after completion. Optional archives enrich the ending without an arbitrary collection quota.

## Milestone 6 — art, effects and audio production

Produce one representative room kit per biome before batching a full art set. Independent far/mid/near layers must tile under bidirectional scrolling; unique landmarks never repeat. Every mechanism needs idle, available, operating and completed poses plus collision/anchor documentation. First effects: local pixel reconstruction, restored material accents and one beacon-light comparison. Then fog, restrained roof shafts, conductor lightning and static-water, measured in the actual renderer.

Music direction: dark, edgy instrumental 8-bit chiptune, abrasive pulse bass, dissonant arpeggios and sharp noise percussion. Current candidates are Dead Carrier; the earlier softer Answering Window candidates are unselected. The tutorial WAV stays available. Each region gets distinct pacing and a related motif only when actual tracks support it; generated tracks are not presumed seamlessly loopable or synchronised stems. Keep music, weather and critical cues independently mixable.

## Milestone 7 — full-game acceptance and release

Audit every required route with minimum abilities, every puzzle state after death/reload, unusual region order, map recall, optional reward value and completed-route returns. Validate combined effects in grayscale, audio muted and reduced motion/flash modes. Measure renderer frame times and loading behaviour on target hardware. Confirm asset/music provenance and permitted use from the actual account/export context. Export a Windows build only after the campaign can be completed and revisited without save loss or progression traps.
