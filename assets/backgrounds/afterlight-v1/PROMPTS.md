# Afterlight parallax sources

Generated with the built-in image generation tool, 12 September 2026. Three independent calls; no external API key or CLI fallback. Original pixels and transparency are preserved. Runtime shader limits luminance and samples on the virtual pixel grid; this does not modify the PNGs.

These are an experimental asset set, not guaranteed seamless tiles or manually cleaned production pixel art. Far sky is used once; mid and near cutouts are placed independently. Compare their readability against the procedural background with G in the study.

Orthographic side view, no playable foreground platforms, no characters, enemies, text, symbols, UI, labels, borders or collage. Quiet, lonely, enormous scale. This is the far sky layer ONLY, not a complete game screenshot. Opaque image.
